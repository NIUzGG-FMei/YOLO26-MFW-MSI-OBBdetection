YOLO26 · Module Architecture

YOLO26 核心模块架构

C3k2、Bottleneck、PSABlock、C3k 四个模块的内部数据流、子层连接与残差关系。

C3k2

C2f 的快速 CSP 实现：cv1 升维 → chunk 拆分为 a/b 两路；a 路进入 n 个 Bottleneck 子层，b 路直连 Concat，最后 cv2 融合输出。

Bottleneck

标准瓶颈块：cv1 内为 Conv2d 1×1 → BN → SiLU，cv2 内为 Conv2d k×k → BN → SiLU，最后可选残差相加。

PSABlock

Attention 内部：QKV Conv → MHSA(QK^T · softmax · V@Attn) → PE + Proj；FFN 内部：1×1 Conv → SiLU → 1×1 Conv，两条残差相加。

C3k

CSP Bottleneck：cv1 主路进入 n 个 Bottleneck（1×1 → k×k → Add），cv2 短路直连，Concat 后由 cv3 融合输出。
