0. 文件总览

类一句话说明是否含可训练参数
SpatialAttentionFree无参数空间注意力：sigmoid(mean_c(x))，生成 (B,1,H,W) 注意力图否
SpatialAttentionMap可训练空间注意力：通道均值+最大值拼接，经 7×7 卷积 + sigmoid是（1 个 Conv2d）
SimAM无参数能量注意力：基于神经科学能量函数，对每个通道/位置加权否
SimACCoM核心模块：多尺度空洞卷积 + 跨尺度空间注意力 + SimAM + 残差融合是（空洞卷积组、restore、SA）
DIF动态插值融合：辅助特征先插值到主特征尺寸，再 1×1 卷积对齐通道后相加是（1 个 Conv2d）
__all__ = ("DIF", "SimACCoM", "SimAM", "SpatialAttentionFree", "SpatialAttentionMap")

为什么相邻分支不需要通道转换？ SA 输出是 (B,1,H,W) 的注意力图，乘到 f'_i 上时通过广播作用于所有通道；对齐只改变空间尺寸，不改变通道数。

3. DIF — Dynamic Interpolation Fusion

class DIF(nn.Module): def __init__(self, c1: int, c2: int | None = None, mode: str = "nearest", bias: bool = True): self.c1 = c1 self.c2 = c1 if c2 is None else c2 self.mode = mode self.cv = nn.Conv2d(self.c2, self.c1, 1, bias=bias) def forward(self, x: list[torch.Tensor]) -> torch.Tensor: main, aux = x # 若尺寸不同，先插值到 main 的 H,W # aux = F.interpolate(aux, size=main.shape[2:], mode=self.mode, ...) return main + self.cv(aux)

DIF 的 主特征 是第一个 from 对应的张量，辅助特征 是第二个 from 对应的张量。只有 1×1 卷积是可训练参数。
