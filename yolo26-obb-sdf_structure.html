4. 结构要点

  • Backbone（0–10）：YOLO26 主干，P3/P4/P5 各 2 个 C3k2，末端 SPPF + C2PSA 得到深层 P5；图中位于左侧纵列。
  • SimACCoM（11/12/13）：分别以 层4(P3) / 层6(P4) / 层10(P5) 为当前分支 cur，虚线分支为跨尺度特征 （prev = 深层特征下采样对齐，nxt = 浅层特征上采样对齐），内部经空洞卷积多尺度增强 + SimAM + 空间注意力门控 + 残差融合。
  • DIF（14/18/22）：main（实线）恒等直连，aux（虚线）插值 + 1×1 卷积对齐后逐元素相加，把 SimACCoM 增强特征注入 FPN 各层。
  • FPN（15–22）：自顶向下，先融合深层 P5（层14），再逐级上采样拼接对应 backbone 特征，最后 DIF 融合 SimACCoM 输出。
  • PAN（23–28）：自底向上，复用已融合的 P3/P4/P5 特征，不重复添加 DIF。
  • Head（29）：端到端 OBB26，输入 22(P3) / 25(P4) / 28(P5) 三个尺度；三条输入连线分别经右侧走廊直达检测头。

# This adaptation intentionally omits Sim-ACCoM1 because the model has no P2 detection head.
# Model docs: https://docs.ultralytics.com/models/yolo26
# Task docs: https://docs.ultralytics.com/tasks/obb

# Parameters
nc: 80 # number of classes
end2end: True # whether to use end-to-end mode
reg_max: 1 # DFL bins
scales: # [depth, width, max_channels]
  n: [0.50, 0.25, 1024] # 3,305,352 parameters, 8.6 GFLOPs at imgsz=640
  s: [0.50, 0.50, 1024] # 12,727,784 parameters, 31.7 GFLOPs at imgsz=640

  l: [1.00, 1.00, 512] # 32,116,648 parameters, 123.4 GFLOPs at imgsz=640
  x: [1.00, 1.50, 512] # 71,841,160 parameters, 274.7 GFLOPs at imgsz=640

# Backbone
backbone:
  # [from, repeats, module, args]
  - [-1, 1, Conv, [64, 3, 2]] # 0-P1/2
  - [-1, 1, Conv, [128, 3, 2]] # 1-P2/4
  - [-1, 2, C3k2, [256, False, 0.25]] # 2-P2/4
  - [-1, 1, Conv, [256, 3, 2]] # 3-P3/8
  - [-1, 2, C3k2, [512, False, 0.25]] # 4-P3/8
  - [-1, 1, Conv, [512, 3, 2]] # 5-P4/16
  - [-1, 2, C3k2, [512, True]] # 6-P4/16
  - [-1, 1, Conv, [1024, 3, 2]] # 7-P5/32
  - [-1, 2, C3k2, [1024, True]] # 8-P5/32
  - [-1, 1, SPPF, [1024, 5, 3, True]] # 9-P5/32
  - [-1, 2, C2PSA, [1024]] # 10-P5/32 deep backbone output

  # SimACCoM args: [pos, kernel, dilations, depthwise, restore_kernel, sa_kernel, e_lambda]
  # Keep the paper's 7x7 kernels and [1,2,3,4] dilation schedule, but use depthwise branches for YOLO26-OBB.
  - [[2, 4, 6], 1, SimACCoM, [2, 7, [1, 2, 3, 4], True, 1, 7, 0.0001]] # 11-P3/8 enhanced
  - [[4, 6, 8], 1, SimACCoM, [3, 7, [1, 2, 3, 4], True, 1, 7, 0.0001]] # 12-P4/16 enhanced
  - [[6, 10], 1, SimACCoM, [4, 7, [1, 2, 3, 4], True, 1, 7, 0.0001]] # 13-P5/32 enhanced

# Neck and OBB head
head:
  # Fuse deep P5 once before the top-down path. DIF channels are inferred from its two `from` entries.
  - [[10, 13], 1, DIF, []] # 14-P5/32 fused

  # Top-down P5 -> P4, then fuse the corresponding Sim-ACCoM3 feature.
  - [-1, 1, nn.Upsample, [None, 2, "nearest"]] # 15
  - [[-1, 6], 1, Concat, [1]] # 16 cat backbone P4
  - [-1, 2, C3k2, [512, True]] # 17-P4/16
  - [[-1, 12], 1, DIF, []] # 18-P4/16 fused

  # Top-down P4 -> P3, then fuse the corresponding Sim-ACCoM2 feature.
  - [-1, 1, nn.Upsample, [None, 2, "nearest"]] # 19
  - [[-1, 4], 1, Concat, [1]] # 20 cat backbone P3
  - [-1, 2, C3k2, [256, True]] # 21-P3/8
  - [[-1, 11], 1, DIF, []] # 22-P3/8 small-object feature

  # Bottom-up PAN path reuses the already fused P3/P4/P5 features without adding duplicate DIF modules.
  - [-1, 1, Conv, [256, 3, 2]] # 23-P4/16
  - [[-1, 18], 1, Concat, [1]] # 24 cat fused top-down P4
  - [-1, 2, C3k2, [512, True]] # 25-P4/16 medium-object feature

  - [-1, 1, Conv, [512, 3, 2]] # 26-P5/32
  - [[-1, 14], 1, Concat, [1]] # 27 cat fused deep P5
  - [-1, 1, C3k2, [1024, True, 0.5, True]] # 28-P5/32 large-object feature

  - [[22, 25, 28], 1, OBB26, [nc, 1]] # 29 OBB26(P3, P4, P5)
